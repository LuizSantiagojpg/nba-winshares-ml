# Atividade Somativa 1 - Modelagem Preditiva de Desempenho na NBA

Repositorio privado contendo o desenvolvimento da Parte 1 da Atividade Somativa 1 de Ciencia de Dados e Machine Learning.

## Arquivos Principais

- `atividade_somativa_1_nba.ipynb`: Notebook Jupyter executado com todas as etapas de exploracao, preparacao de dados, selecao de atributos (`SelectKBest`), definicao do problema (Regressao), divisao treino/teste (75%/25%), treinamento (`RandomForestRegressor`) e predicao/avaliacao.
- `atividade_somativa_1_nba.html`: Versao exportada em HTML do notebook para visualizacao direta.
- `nba_stats.csv`: Base de dados utilizada na analise.

## Resultados Obtidos na Base de Teste (25%)

- **R2:** 0.8600 (86.00%)
- **MAE:** 0.7091
- **RMSE:** 1.1476
